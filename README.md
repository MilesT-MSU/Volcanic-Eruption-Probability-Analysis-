# Volcanic-Eruption-Probability-Analysis-
If a volcano has erupted once, what is the probability it will erupt again?


•	Analyzed a Kaggle data set of 898 eruption records to estimate the recurrence of volcanic activity 
•	Used Python to clean the data and then build a grouped mean prediction model, by volcano type, tectonic region and activity category 

https://www.kaggle.com/datasets/kanchana1990/global-volcano-eruption-intelligence 

This dataset has a record of 898 significant volcanic eruptions from 4360 BC
to 2025


limitations:
reporting bias favors well monitored regions
rare volcano types (less than 5 records) should have been exclided
model predicts if it will erupt again not when. 
there is a large lack of data from times further in the past
